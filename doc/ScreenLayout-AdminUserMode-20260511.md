## ねらい

タブ + コンボボックス構造をやめ、**左サイドバーのモード切替トグル + リンク状モデル一覧** によって「今いるモード」と「選択中のモデル」を常時可視化する。

- ヘッダー (上端) : アプリ識別 + 管理者モード時のみグローバルツールバー
- サイドバー (左) : 最上部にモード切替 → モデル一覧 → モード別アクション
- メインペイン (右) : 選択中モデルに応じた `ModelEditor` (admin) / `CrudView` (user)

## 5. インタラクション仕様

### モード切替
- サイドバー最上部のセグメント型トグルをクリック → モードが反転 → localStorage `modeler:ui:mode:v1` に保存
- `selectedKey` は **モードごとに別途保持** する (admin と user で同じモデル名でも別文脈)
  - 例: admin で `customer` を編集中 → user に切替 → user 側の選択は空 (またはユーザーモード前回値) → admin に戻ると編集対象に戻る
- `useModelerViewModel` は AppShell の親で 1 インスタンスのみ生存 (undo 履歴と下書きを保つ)

### モデル選択
- サイドバー行をクリックで選択 → ハイライト + メインペイン更新
- 選択中行は左ボーダー (青) + 太字 + 軽い背景

### 並び替え (管理者モード)
- 行ホバーで ⋮ メニュー出現
- メニュー内「↑ 1つ上へ」「↓ 1つ下へ」で `vm.moveModel(from, to)`
- 端 (先頭/末尾) では該当方向ボタンを disable
- (オプション) DnD は Step 3 Task 4 では実装せず、後続候補

### 行アクション (管理者モード)
- ⋮ ボタンクリックでポップオーバーが下方に表示 (`SqlExportButton` の絶対配置パターンを参照)
- 項目: 定義を編集 / 1つ上へ / 1つ下へ / モデルを削除
- 「モデルを削除」はデプロイ済みなら `ConfirmDialog` を出し、未デプロイ (= draft のみ) なら即時削除でよい

### 並び順の反映
- 推奨: 「並び順の変更はデプロイ後に反映されます」をサイドバー末尾に常時 (薄字) 表示
- 即時反映を選ぶなら Step 3 で Task 7 (`PATCH /meta/reorder`) を追加

### 狭幅対応
- ヘッダー左の ☰ ボタンでサイドバーを開閉
- < 1024px はオーバーレイ表示 (本体スクロールを止め、暗背景)
- ≥ 1024px は常時展開、☰ は非表示 (あるいは折りたたみで本体幅を広げられるオプション)
